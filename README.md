# 📚 Today I Learned

> 오늘의 배움이 내일의 실력이 되도록
> *"가장 희미한 잉크가 가장 강력한 기억보다 낫다."*


---

"아, 이거 이해했다!" 하고 넘어갔던 것도 며칠 지나면 거짓말처럼 머릿속에서 사라지곤 했다. 내 기억력만 믿기엔 공부할 게 너무 많다.

그래서 오늘 배운 내용이랑 프로젝트 하면서 머리 쥐어뜯었던 에러들을 하나씩 남겨두기로 했다.  
나중에 또 같은 문제로 막혔을 때 바로 찾아볼 수 있고, 시간이 지나서 내가 얼마나 성장했는지 돌아볼 수 있는 좋은 자료가 될 것이다.  
날짜를 따로 적지 않는 건 날짜 칸을 비우지 않아야 한다는 강박에 쫓기다 포기하고 싶지 않아서다.

남들보다 걸음은 조금 느릴지 몰라도, 멈추지 않고 매일 적다 보면 어제보다 나은 개발자가 되어있을거라 믿는다.

기록은 결국 기억을 이긴다. 어제보다 한 걸음 더 성장한 나를 기대해 본다.
